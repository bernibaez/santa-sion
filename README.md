# Santa Sion 4.0
Node.js 20+; npm install; npm run dev. npm run build para verificar compilación.
Modelos GLB locales originales generados por generate_models.py (Python, numpy, trimesh). No se requiere Python para jugar. Los modelos son estilizados procedurales, no modelos comerciales ni rigged. Animación de alas y traslado mediante Three.js. Conserva tour, voz del navegador y exploración de v3. No se pudo instalar dependencias en el entorno de creación; compilación y prueba visual pendientes. Los GLB fueron reabiertos con trimesh correctamente.

## Expansión 4.1
Terreno 460 x 600; límites de exploración x ±71, z -380 a 60. Se amplían río, mar, ruta, murallas y decoración. Compilación y rendimiento pendientes de prueba local.

## v4.2
Colisiones de desplazamiento manual con huellas de obstáculos y deslizamiento por paredes. Trono y modelo GLB sentado original; cámara final ajustada. La cámara cinematográfica no usa física.

## v5.0 — La Gloria Celestial
- Vestiduras blancas emisivas HDR y adornos dorados en jesus-seated.glb.
- Árbol con 72 frutos visibles, 12 paletas artísticas y ramas; cámara dirigida a la copa.
- Luces locales del trono, anillos y partículas animadas; mar iridiscente.
- Las 12 paletas son una interpretación visual, no una identificación bíblica de variedades.
- Conserva mapa y colisiones de v4.2. La luz ambiental sigue siendo simulada.
